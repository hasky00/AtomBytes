Atombytes

An adapter from atoms to bytes. Drop a photo of a physical object, get a stable fingerprint, hash it, and anchor the hash as a Nostr event. v0.2 lets you crop to the part of the object that counts.

The raw file hash proves "this exact photo existed". The Atombytes hash proves "an object that looks like this existed", and it survives small changes in angle and light. v0.3 will fingerprint close-up features only one object has.
